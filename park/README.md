# わくわく知育パーク

4〜5歳向けの知育ミニゲーム集です。大きなボタンと明るい画面で、タッチ操作だけで遊べます。
既存のやさしい内容から一歩進んだチャレンジ難易度です。

## 遊び方

1. `index.html` をブラウザで開く（または下のローカルサーバー）
2. 好きなゲームをタッチ
3. 正解するとスターが貯まる

## ゲーム一覧（10種）

| ゲーム | ねらい | レベルアップ内容 |
|--------|--------|------------------|
| いろあわせ | 色の認識 | 10色・色名指定・6択 |
| かぞえよう | 数える力 | 1〜10・混在カウント |
| めくりカード | 記憶・集中 | 6ペア（12枚） |
| かたちさがし | 形の認識 | 8種・同色ちがいかたち |
| つぎはなに？ | 規則性 | AB / AABB / ABC パターン |
| おおきさくらべ | 大小比較 | 4段階の大きさ |
| なかまはずれ | 分類 | 仲間外れを探す |
| かげあて | 形の照合 | シルエット当て |
| たしざん | 数の合成 | 絵で足し算（合計〜10） |
| ひらがな | 文字と絵 | 読み⇔絵のマッチ |

各ゲームは原則8ラウンドです。

## 起動

```bash
# どれか一つでOK
npx --yes serve .
# または
python -m http.server 5500
```

ブラウザで表示された URL（例: `http://localhost:3000`）を開いてください。
