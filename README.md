# チャレンジ知育ラボ

10歳前後向けの知育チャレンジアプリです。スコア・コンボ・制限時間で「ゲーム感覚」の頭脳トレーニングができます。

## チャレンジ

| ゲーム | 内容 |
|--------|------|
| けいさんバトル | 四則演算のタイムアタック（60秒） |
| すうじパズル | 数列のきそくを見つけて穴埋め |
| いみマッチ | 反対語・仲間・意味の選択 |
| メモリープラス | 8ペアの記憶マッチ（90秒） |

## 起動

```bash
npx --yes serve . -p 5501
```

ブラウザで `http://localhost:5501` を開いてください。
